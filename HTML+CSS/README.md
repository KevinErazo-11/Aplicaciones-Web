# Workshop 2: Web Applications (HTML + CSS)
Este directorio contiene la evolución del sitio web del Workshop 1. 
Se implementó un diseño profesional y responsivo utilizando CSS modular. Los estilos fueron divididos en archivos específicos (`global.css`, `tables.css`, `forms.css`) para mejorar la mantenibilidad y organización del código, implementando variables de color y una paleta de tema oscuro.
