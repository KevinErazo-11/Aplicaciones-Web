Courses I Am Currently Taking

Web Applications

Instructor: Prof. Francisco Javier Hidrobo Torres

Main topics: Front-end technologies (HTML, CSS, JS, Bootstrap), version control with Git, RESTful APIs, back-end development, databases, and Docker containerization.

  1. Build interconnected responsive web applications using semantic HTML5 and CSS
  2. Design and integrate REST APIs with back-end frameworks and databases
  3. Deploy web applications using Docker containerization and cloud platforms

Related resource: MDN Web Docs - HTML

Theory of Computation

Instructor: Prof. Israel Gustavo Pineda Arias

Main topics: Automata theory, formal languages, grammars, Turing machines, decidability, and computational complexity (P vs NP).

  • Master finite state machines and regular expressions
  • Understand the fundamental limits of computation via Turing machines
  • Classify algorithmic problems by complexity classes

Intelligent Agents

Instructor: Prof. Tito Rolando Armas Andrade

Main topics: Agent architectures, search algorithms, multi-agent systems, decision-making frameworks, and Markov Decision Processes.

  1. Implement search strategies for autonomous problem solving
  2. Model complex environment interactions using MDPs and decision theory
  3. Design cooperative and competitive multi-agent systems

Machine Learning

Instructor: Prof. Juan Pablo Astudillo León

Main topics: Supervised and unsupervised learning, regression, classification, neural networks, model evaluation, and hyperparameter tuning.

  • Implement classification and regression models from scratch and with frameworks
  • Optimize model performance using cross-validation and hyperparameter tuning
  • Apply deep learning architectures to complex datasets

Image Processing

Instructor: Prof. María Gabriela Cajamarca Morquecho

Main topics: Digital image representation, spatial filtering, frequency domain analysis, edge detection, image segmentation, and feature extraction.

  1. Apply spatial and frequency filtering techniques to enhance images
  2. Implement feature extraction and edge detection algorithms
  3. Perform image segmentation for object and land-cover analysis

Scientific Communication Workshop

Instructor: Prof. Christian Andrés Tirado Espín

Main topics: Academic writing, technical reporting, research paper structure, peer review process, and effective scientific presentations.

  • Structure rigorous scientific reports and academic papers in LaTeX
  • Effectively communicate complex technical findings to scientific audiences
  • Master academic citation, peer review, and research methodology
